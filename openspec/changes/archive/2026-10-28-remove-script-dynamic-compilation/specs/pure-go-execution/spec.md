# Spec Delta

## MODIFIED Requirements

### Requirement: Full supported language execution
Runtime MUST исполнять runtime-конструкции поддерживаемой стабильной версии TypeScript в объявленном профиле без компиляции строк. Типовые конструкции SHALL обрабатываться при компиляции; остальные поддерживаемые конструкции MUST сохранять семантику языка. Исключения для встроенного `eval`, конструкторов функций из строк и загрузки неподготовленных модулей MUST явно указываться в заявлении совместимости.

#### Scenario: Runtime-bearing TypeScript constructs
- **WHEN** корректный проект использует enum, namespace, parameter properties, decorators и resource management, допустимые выбранной конфигурацией
- **THEN** наблюдаемые значения, побочные эффекты и порядок выполнения соответствуют поддерживаемому TypeScript

#### Scenario: TSX execution with host JSX API
- **WHEN** TSX-проект успешно проверен и приложение зарегистрировало требуемую JSX factory или JSX runtime-модуль
- **THEN** JSX-выражения исполняются через предоставленные привязки без встроенной зависимости от браузера или React

#### Scenario: Declared compatibility boundary
- **WHEN** приложение или пользователь проверяет заявленную поддержку языка
- **THEN** документация явно сообщает о недоступности компиляции строк и ограничении динамического импорта подготовленным набором

### Requirement: Standard language environment
Runtime SHALL предоставлять стандартные объекты языка и операции, соответствующие объявленному профилю без компиляции строк. Стандартные объявления checker MUST соответствовать профилю и MUST NOT неявно включать DOM или Node.js API. Объектная модель функций и обычные операции вызова MUST сохраняться при запрете конструкторов кода из строк.

#### Scenario: Standard collections and asynchronous values
- **WHEN** программа использует стандартные массивы, Map, Set и Promise поддерживаемой среды
- **THEN** checker видит соответствующие типы, а runtime предоставляет соответствующие реализации

#### Scenario: Ordinary functions remain usable
- **WHEN** программа создаёт функции из исходника, замыкания, async/generator-функции и использует `call`, `apply`, `bind` или `instanceof Function`
- **THEN** эти операции работают без предоставления возможности компилировать строку

## ADDED Requirements

### Requirement: No built-in source string execution
Среда MUST NOT предоставлять встроенный `eval`. Вызов или конструирование любого встроенного конструктора функций из строк MUST завершаться `EvalError` до преобразования аргументов в строки. Запрет MUST действовать независимо от алиасов, прототипов и способа вызова и MUST NOT иметь настройки включения.

#### Scenario: Eval is absent
- **WHEN** скрипт читает `(globalThis as any).eval` в стандартном окружении
- **THEN** получает `undefined`, а собственное свойство `eval` у стандартного глобального объекта отсутствует

#### Scenario: Reserved host global name
- **WHEN** приложение пытается зарегистрировать глобальную host-привязку с именем `eval`
- **THEN** типизированный реестр явно отклоняет регистрацию, а методы объектов вроде `api.eval()` остаются допустимыми

#### Scenario: Constructor reached through a prototype
- **WHEN** скрипт получает встроенный конструктор через `.constructor` обычной, async, generator или async-generator функции и пытается создать функцию
- **THEN** возникает `EvalError`, а новый исполняемый код не создаётся

#### Scenario: Alternate invocation and coercion
- **WHEN** встроенный конструктор вызывается через алиас, `call`, `apply`, bound function, Proxy или `Reflect.construct` с объектом, имеющим побочный эффект в `toString`
- **THEN** конструктор отклоняет операцию до собственного преобразования аргумента в строку; переданный текст не проверяется и не исполняется

### Requirement: Host-owned compilation boundary
Публичные Go API проверки, компиляции и выполнения исходника MUST оставаться доступны приложению. Встроенные операции скрипта MUST NOT загружать или компилировать новые исходники. Возможности явно зарегистрированных приложением callback-функций MUST документироваться как ответственность приложения.

#### Scenario: Host compiles another version
- **WHEN** Go-приложение явно вызывает `Compile` или `RunScript` с новым исходником
- **THEN** исходник проходит обязательную проверку и может выполняться независимо от запрета встроенной компиляции строк в скрипте

#### Scenario: Host explicitly grants a compiler callback
- **WHEN** приложение самостоятельно регистрирует callback, выполняющий компиляцию
- **THEN** этот callback является явной host-возможностью, а документация не обещает изоляцию от возможностей, предоставленных самим приложением
